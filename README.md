# DSH SOLO (Trae SOLO Mode Workbench for DSH)

在 DSH (DeepSeek Harness) 桌面端完整复刻 **Trae SOLO 模式**的三合一工作台插件：集**全功能 VS Code 代码编辑器**（`</> 编辑器`）、**交互式预览浏览器**（`🧭 浏览器`）与**独立交互式终端**（`>_ 终端`）于一体。

---

## ✨ 核心特性

### 1. 独立 VS Code 代码编辑器 (`</> 编辑器`)
- **完整 VS Code 生态**：内置基于 OpenVSCode Server 1.109.5 的现代工作台，支持语法高亮、IntelliSense、跳转定义、`Ctrl+P`、`Ctrl+Shift+P`。
- **1:1 复刻 Trae SOLO 布局**：编辑区居左，资源管理器/搜索/Git/插件市场横置于**右侧顶部活动栏**；自动折叠隐藏次侧边栏（auxiliarybar），无多余空白。
- **自动保存**：默认启用 `files.autoSave: "afterDelay"`（500ms 自动保存）。
- **右键「添加到会话」**：
  - 划选代码后右键 → **「添加到会话」**：在输入框生成紧凑代码行号胶囊（如 `[ gemini-check.sh 24-31 ]`），发送给模型时展开为带完整行号与代码块的内容。
  - 文件树与标签页右键 → **「添加到会话」**：生成文件/目录引用芯片。
- **双向深浅色主题自适应**：自动跟随 DSH 系统深浅色外观热切换（深色翡翠绿高亮，浅色优雅灰白）。

### 2. 交互式预览浏览器 (`🧭 浏览器`)
- **多子标签页管理**：支持新建多个页面标签、前进/后退/刷新与本地端口（如 `3000`、`5173` 等）一键快捷直达。
- **元素选择模式 (Inspect Mode)**：
  - 点击工具栏鼠标指针图标开启，悬停呈现翡翠绿高亮框与语义化标签（`Button`, `Input`, `Image`, `Item` 等）。
  - 点选元素弹出浮动工具栏，支持一键 **「✦ 添加到对话」** 与 **「快捷编辑文案」**。
  - 支持按 `Escape` 随时退出选择模式。
- **实时样式与文案抽屉 (`<>`)**：
  - 侧边抽屉提供可视化调色盘（文字颜色、背景色）、字号/字重、内外边距、圆角、Display 布局与自定义 CSS 输入框。
  - 实时调整页面显示，并支持一键将修改后的目标 CSS 与源码定位发送到会话。
- **集成控制台日志**：
  - 自动捕获页面的 `console.error`、`console.warn` 与未捕获异常。
  - 底部抽屉提供筛选与一键 **「✦ 添加到对话」**。

### 3. 独立交互式终端 (`>_ 终端`)
- **完全自包含 PTY 后端**：不依赖任何第三方终端插件，内置多进程终端调度与 200KB 滚动快照回放。
- **多 Shell 切换**：内置 `zsh`、`bash`、`fish`、`sh` 标签切换与新建子标签。
- **划选文字一键引用 (`Ctrl+U`)**：
  - 在终端内用鼠标划选任意行，右侧自动浮现 **`[ ✦ 添加到对话 Ctrl+U ]`** 按钮。
  - 支持快捷键 **`Ctrl + U`**（macOS 为 `Cmd + U`）将选中文本与行号范围送入会话输入框。

### 4. 引用胶囊与已发送消息原生折叠
- **输入框阶段**：所有引用均保持紧凑优雅的胶囊形态（`[ ✦ div ]`、`[ ✦ 控制台日志 (1) ]`、`[ >_ Terminal 1-1 ]`），绝不直接向输入框倾泻大段 HTML/代码。
- **发送提交阶段**：通过内置序列化器自动展开为完整的结构化 Markdown，保证大模型与其他无插件客户端（CLI、移动端、JSONL 日志）获取最全上下文。
- **已发送气泡阶段**：自动折叠为紧凑徽章，支持 **鼠标悬停预览详情卡片** 与 **点击弹窗查看完整内容、一键复制或重新引用**。

## 🚀 跨机器部署与同步指南

当你需要将此插件同步到另一台新机器上使用时：

### 第一步：在另一台机器上克隆仓库
```bash
git clone <你的私有Git仓库地址> ~/my-file/dsh-trae-solo
cd ~/my-file/dsh-trae-solo
```

### 第二步：运行一键初始化脚本
```bash
./setup.sh
```
> **脚本会自动执行**：
> 1. 自动检测系统架构并下载/解压对应版本的 `openvscode-server-v1.109.5` 核心服务。
> 2. 自动注入本仓库内建的完整简体中文语言包支持（`nls.messages.zh-cn.js`）。
>
> *注：如果该机器网络受限，也可将原机器的 `~/.dsh/cache/openvscode-server-v1.109.5` 打包传过来，或直接执行 `./setup.sh <本地压缩包路径>`。*

### 第三步：在 DSH 中安装 / 链接本插件
在宿主机的 DSH 环境中执行安装（或通过 DSH 插件管理器）：
```bash
dsh plugin install "$HOME/my-file/dsh-trae-solo"
```

### 第四步：后续日常更新同步
在任意机器上修改并 `git push` 后，另一台机器只需执行：
```bash
cd ~/my-file/dsh-trae-solo
git pull
```
DSH 的热重载（HMR）会自动检测并应用最新的插件代码。

## 📁 仓库目录结构

```text
dsh-trae-solo/
├── client.js          # Web 前端完整模块（编辑器/浏览器/终端标签页、胶囊渲染、快捷键）
├── index.js           # Host 后端服务（openvscode-server 启动与布局补丁、PTY 调度、代理路由）
├── cordis.patch.yml   # Cordis 加载器补丁配置
├── icon.svg           # 翡翠绿 SOLO 品牌图标
├── package.json       # DSH 插件 Bundle 清单定义
├── setup.sh           # 新机器一键依赖安装与初始化脚本
├── resources/         # 离线静态资源（简体中文 NLS 映射表等）
│   └── nls.messages.zh-cn.js
├── locale/            # 插件元数据多语言字典 (zh.json, en.json)
└── README.md          # 详细使用与部署说明文档
```
